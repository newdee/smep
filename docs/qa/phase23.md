# Phase 23 — Vim's `:s` and `:set`, and Vim's patterns (2026-11-16)

The request: "把 :s 替换和 :set 也加上". Asked and answered before building: patterns are Vim's regular expressions everywhere (`/`, `?`, `n`, `*`, the highlight and `:s`), not literal text; `:set` lasts for the run, as Vim without a vimrc.

## Design

- `src/vim/pattern.rs`: `Pattern::new` translates Vim's syntax to the `regex` crate's (already in the tree through gpui-base; now a direct dependency, `1.10` for `\b{start}` / `\b{end}`). Magic by default; `\v`, `\m`, `\M` / `\V`; `\c` / `\C`; `\( \) \%( \| \+ \? \= \{n,m} \{-…}`, `\< \>`, classes (`\d \s \w \a \l \u \x \o \h`, `[…]` with POSIX classes), `\n` as `\r?\n`, `~` as the last replacement; `^` / `$` only where Vim takes them as anchors, a quantifier with nothing before it literal. Compiled with `multi_line` and `crlf`, so `$` stops before `\r\n` and `.` matches no line break. What the crate cannot do (back references, `\zs`, look-around, `\%[`) is an error with a message, never a silent change of meaning; bad patterns give Vim's E54 / E61 / E554 / E383.
- Case: 'ignorecase', 'smartcase' (an upper-case letter not after `\`); `*` / `#` escape the word, skip 'smartcase' and keep the old whole-word rule (Vim's word classes, CJK apart), rather than `\<\>`, so mixed Latin/CJK text behaves as before. A `:set ic` recompiles the last search (`n`, the highlight follow it).
- `src/vim/ex.rs`: `parse_range` (`%`, `.`, `$`, `N`, `'<`, `'>`, `+N` / `-N`, `,` / `;`, a backwards range swapped, E16 / E20), `parse_substitute` (any delimiter but letters, digits, `\`, `"`, `|`; `\` + delimiter; flags `& g i I n e`, `c` refused, trailing text E488), `Options::set` (`opt`, `noopt`, `invopt`, `opt!`, `opt?`, `opt&`, `sw=`, `+=`, `-=`, `^=`; several at once; stops at the first error, E518 / E521 / E487 / E474).
- `:s` (`Vim::substitute`): matches starting in the range, one per line without `g`, an empty match right after a match skipped (Vim's rule: `:s/x*/-/g` on `abc` gives `-a-b-c-`, on `aa` gives `-`), never a match that starts or ends inside a CRLF. Replacement: `&` / `\0`, `\1`…`\9`, `\r` (and `\n`) a line break in the document's own style, `\t`, `\u \l \U \L \E`, `~`. One edit trimmed to the changed span (one undo step); the cursor on the line the last replacement ends on, at its first non-blank; the pattern becomes the last search, highlighted. `:s` / `:&` repeat without the flags, `:&&` with them. Reports "N substitutions on M lines" over 'report', "N matches on M lines" for `n`, E486 unless `e`.
- `:` in Visual mode ends Visual mode (setting `'<` `'>`, collapsing the selection) and opens the line with `'<,'>`, the caret after it.
- `:set`: `hlsearch`, `ignorecase`, `smartcase`, `wrapscan` (off: E384 / E385 where a match exists only round the end), `shiftwidth` (1–99; `>`, `<` and the source editor's Tab), `number`, `wrap`. `Op::Options` tells the app; `Smep::apply_editor_options` sets every tab's editor (`set_line_number`, `set_soft_wrap`, `set_tab_size`), new tabs too, and smep's own look while Vim mode is off.
